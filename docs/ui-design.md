# Phase 1.5 UIデザイン

既存の画面構成を維持し、ネイビーを中心に視認性を改善しました。

- 基本色：メインネイビー `#0F2747`、サブネイビー `#163A63`、アクセントレッド `#D7263D`、背景 `#17283D`、ライトグレー `#E5E7EB`、本文 `#122033`、白 `#FFFFFF`。
- テーマ色は `src/style.css` のCSS変数へ集約。白いカード内の補助文字は `#48586D`、暗い背景上は `#C8D6E8` を使用します。
- 全体背景は `#17283D`、ヘッダー・下部ナビは `#0F2747`。白文字・明るい補助文字を使用します。
- MY CLUBカードは `#163A63` に明るい枠と球団カラーバーを組み合わせて背景から区別します。情報カードは白を維持します。
- アクセントレッド `#D7263D` は開始・手動保存の主要ボタンに限定します。選択中ナビは白い上線と明るいネイビーで強調し、フォーカス表示は青です。レッドリーグの識別色は落ち着いた赤 `#A33C50` とし、既存の球団カラーも維持します。
- リーグの青／赤は所属、球団ごとのカラーバーは球団の識別に使います。既存の球団カラーは維持しています。
- セーブ一覧は球団カラーバーを追加し、プレイ中の行は背景・枠・白文字のラベルで強調します。
- 無効ボタンはグレーで区別します。タップ領域44px以上とキーボードのフォーカス表示を維持します。
- 画面の区切りと見出しを強め、スロット番号は等幅数字で表示します。下部アイコンは文字色と連動するSVG線画です。

IndexedDBの保存形式、球団名・所属、セーブ処理およびゲーム機能は変更していません。
