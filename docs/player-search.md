# Phase 2D：選手検索・比較

下部「選手」で、現在読み込んでいるセーブの公開選手DTOだけを検索します。初期表示は自球団76人。検索・並べ替え・ページ追加は画面内で完結し、DBの書き込みや選手の再生成をしません。schemaVersion 2、DBバージョン、v1移行、球団固定、生成係数は変更していません。

## 表示仕様

- 対象：自球団／全球団／ブルーリーグ／レッドリーグ／個別12球団。自球団・全球団には切り替えボタンもあります。
- 名前：姓・名の部分一致。NFKCで全半角を揃え、英字大小、空白、中黒、ひらがな・カタカナを正規化します。漢字の読み仮名は推測しません。
- 折りたたみ式の詳細条件：投手・野手、支配下・育成、主守備位置、年齢上下限、投げ方、打ち方、外国人区分。
- 能力条件：野手の対右・対左ミート、パワー、走力、盗塁、捕球、スローイング、肩力、8守備位置の適性。投手の球速、制球、スタミナ、先発・救援適性。個別能力を1つ選び、その下限・上限で判定します。
- 条件はすべてAND。上下限は両方の境界を含み、片側だけの指定も可能です。未入力は制限なし。数値は非負の安全な整数、0〜100系能力はその範囲内、球速はkm/hです。年齢・球速に新たなゲーム上限は設定しません。不正値や下限＞上限はエラーを表示し、結果を出しません。
- 能力を切り替えると、その上下限を解除します。異なる単位の数値が残ることを防ぎます。
- 並べ替え：標準の種別順、名前、年齢、年俸、上記21個の個別能力。それぞれ昇順・降順を選べます。名前は正規化後の日本語照合順、数値は保存値そのもので比較し、ランクや総合スコアを使いません。同値なら選手IDの昇順で安定させます（降順指定時も同じ）。
- 投手・野手の専用能力は、その能力を持つ種別だけが検索・並べ替え対象です。対象外選手を0点として扱いません。矛盾する種別・能力を指定した場合は0人になります。現在の条件を一覧上に表示します。
- 結果人数と表示人数を表示し、カードには必ず所属球団・種別・登録区分を表示します。選択した比較能力、年俸順なら年俸も表示します。0人は「条件に一致する選手はいません」。
- 80人ずつ表示し、「さらに表示」で80人追加します。この件数はスマートフォン向けの表示上の暫定値（`PlayersScreen.tsx`の`PAGE_SIZE`）で、ゲーム内仕様や登録上限ではありません。
- 標準は投手・野手のグループ表示。それ以外の並べ替えはグループに分けず、選択したキーで全結果を通して並べます。
- 詳細は既存の能力・成績・成長・契約タブを維持。一覧へ戻ると検索条件、折りたたみ状態、追加表示件数、スクロール位置と選択カードへのフォーカスを復元します。
- 「条件をすべて解除」で自球団・標準順・無条件へ戻します。スロット変更・画面を開き直すと自球団から開始します。ページ再読み込みでは検索条件を保存しませんが、選手データは同じ保存値を読みます。

## 分離と保護

`src/game/players/search.ts`は`PublicPlayer`配列を受ける純粋な検索処理です。条件と比較可能な能力を型・ホワイトリストで定義し、保存・生成処理へ依存しません。入力配列を変更せず、結果配列だけを並べ替えます。

`PlayerSearchControls`は条件入力と説明、`PlayerCard`は公開能力の表示、`PlayersScreen`は読み込み・条件状態・ページ追加・詳細遷移を担当します。`readPublicRoster`の公開DTO境界を維持し、非公開の成長タイプ・潜在上限・乱数状態を渡しません。検索条件にも使用しません。

セーブ切替時はセーブIDで画面を初期化し、古い非同期読み込みを無視します。未選択・破損・未対応データの既存エラー処理を維持し、問題データを初期化・削除・上書きしません。

## 手動確認

1. `npm run dev`で起動し、セーブを読み込んで「選手」を開きます。自球団76人を確認します。
2. 「全球団」に切り替え、912人、両リーグ各456人、各球団76人を確認します。姓・名の一部を入力して検索します。
3. 詳細条件を開き、投手・育成・年齢などを組み合わせ、球速や制球の境界値を指定します。逆転範囲はエラー、矛盾条件は0人になることを確認します。
4. 個別能力・守備適性・年俸・年齢の昇順と降順を切り替えます。カードの値と詳細の値を比較します。
5. 「さらに表示」後、下の選手を開き、一覧へ戻って条件・件数・位置を確認します。「条件をすべて解除」で自球団に戻します。
6. ホームから別スロットを読み込み、前の検索条件が残らず自球団になることを確認します。再読み込み後も能力・経歴が変わらないことを確認します。
7. スマートフォン縦画面で詳細条件を開き、横スクロールせず下部5メニューも操作できることを確認します。
