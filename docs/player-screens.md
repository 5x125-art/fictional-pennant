# Phase 2C：保存済み選手の閲覧

## 画面と操作

下部メニューの「選手」で、操作中のセーブに保存された選手を閲覧します。初期表示は自球団です。球団セレクトでブルー／レッド両リーグの12球団を切り替えられます。検索、並べ替え、高度な絞り込みは追加していません。

一覧は投手・野手の2グループです。各選手に名前・年齢・投打・主守備位置・支配下／育成区分と主要能力を表示します。野手は対右／対左ミート・パワー・走力、投手は球速・制球・スタミナです。選手のカードをタップすると詳細へ進み、「選手一覧に戻る」で同じ球団の一覧に戻れます。

### 詳細タブ

| タブ | 表示 |
|---|---|
| 基本情報・能力 | 野手の9能力と全8守備位置の適性、または投手の球速・制球・スタミナ・先発／救援適性・役割・所持球種ごとの球威／制球／変化量。体力と調子も表示 |
| 成績 | 保存済みの架空の過去年度成績。1軍・2軍を別表示。最新の年度を先頭にし、年度の見出しで開閉 |
| 成長 | 「成長記録は準備中」のみ |
| 契約 | 年齢・入団経歴・入団年齢・完了済みプロ在籍シーズン数・支配下／育成・年俸（万円）・契約年数・外国人選手のフラグ |

0〜100系の能力は共通の`abilityRank`によるS〜Gを数値と併記します。球速はkm/h、弾道と球種変化量は従来の固有単位で表示し、ランクを付けません。総合能力・特殊能力・捕手リード・画像はありません。契約の残り期間、FA資格、国籍など、保存データにない情報は推測して追加していません。

選手画面の詳細タブは、左右矢印キー・Home・Endでも移動できます。タップ領域と文字サイズ、数値・ランクのコントラストを確保し、スマートフォンは一覧1列・能力2列、PCは一覧2列・基本能力4列で表示します。ホーム画面と下部メニューの構成、ダークネイビーのデザインは維持しています。

## 成績の表示仕様

| 項目 | 計算・表記 |
|---|---|
| 打率 | 安打÷打数、小数3桁。例：1÷3は`.333`。打数0は`—` |
| 防御率 | 自責点×27÷アウト数、小数2桁。例：自責点1・4アウトは`6.75`。アウト0は`—` |
| 投球回 | アウト数の商と余り。3アウト=`1.0`、4アウト=`1.1`、5アウト=`1.2`。小数以下は端数アウトで、小数の回数ではない |
| シーズン | -1は「1シーズン前」、-2は「2シーズン前」。実暦年へ変換しない |
| 未出場 | 当該1軍／2軍記録の試合数0に「未出場」を表示。件数は保存値0、分母0の率は`—` |
| 過去記録なし | 保存済みの過去成績がないことを表示。今季の0成績などを作らない |

野手は打席・打数・安打・長打内訳・打点・得点・四死球・三振・盗塁／盗塁死・犠打／犠飛を表示します。投手は登板・先発・投球回・勝敗・セーブ／ホールド・奪三振・与四球・被安打／被本塁打・失点／自責点を表示します。各年度の所属球団と年齢も保存値です。

画面上で「初期生成時の架空の記録」「試合処理は未実装」「今季成績はありません」と明示します。今季データの生成、試合の計算、成績の書き込みは行いません。

## データ境界とエラー

- `src/storage/playerViews.ts`：`readGameSave`で検証済みのschemaVersion 2を読み、`readPublicRoster`として公開DTOだけを返します。生成・移行・書き込みは行いません。
- `src/game/players/publicPlayer.ts`：現在能力・契約・経歴・成績も含め、すべてのネストをホワイトリストでコピーします。元データの未知フィールドは引き継ぎません。
- Reactが受け取るのは`PublicRoster`と`PublicPlayer`です。`developmentByPlayerId`、成長タイプ、能力別潜在上限、生成シードや乱数状態は含めません。
- セーブ変更時は選手画面を別のセーブIDで初期化し直します。読み込み中に前の非同期処理が完了しても、古い選手が混入しないようにします。
- セーブ未選択ならホームへの案内、読み込み失敗・破損ならエラーと再読み込みボタン、存在しない選手IDなら一覧へ戻る案内を表示します。問題データを初期化・再生成しません。
- 画面を開き直すと自球団から表示します。ページ再読み込み後は従来どおりホームから開始し、選手メニューで保存済みの同じ情報を確認できます。

DBバージョン・schemaVersion・選手型・生成処理・既存の移行処理は変更していません。旧v1は既存のスロット読み込みでv2へ移行された後、選手画面から閲覧できます。選手画面の読み込みだけで日時や選手が変わらないことも検証しています。

## 検証と手動確認

```sh
npm run typecheck
npm test
npm run build
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

型チェック、自動テスト107件、ブラウザテスト28件、本番ビルドが成功しています。新規の検証には12球団の人数と保存値との一致、投手・野手の各能力と球種、ランク、打率・防御率・投球回、分母0、公開DTOの未知フィールド除外、非公開情報の非表示、契約、詳細タブのキーボード操作、一覧への復帰、再読み込み、スロット切り替え、破損データの保護を含みます。既存の保存・移行・容量不足・復元失敗時の回帰テストも通過しています。

手動確認：

1. `npm run dev`で起動し、新規セーブを作成するか既存スロットを読み込みます。
2. 下部の「選手」を押し、自球団の一覧と投手・野手、支配下・育成の表示を確認します。
3. 表示球団を切り替え、他の11球団も確認します。
4. 野手と投手の詳細を開き、能力・成績・成長・契約タブを確認します。成長タブは準備中です。
5. 一覧へ戻り、ホームから別スロットへ切り替えて、選手もそのスロットの自球団へ切り替わることを確認します。
6. 再読み込み後に同じ選手・能力・過去成績が表示されることを確認します。
